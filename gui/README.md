# native-gui（库模块）

MoonBit 原生跨平台桌面 GUI 库：自绘控件 + 自定义主题，Windows / Linux 原生运行，macOS 后端暂未开发。

本目录是**库模块**（`moon.mod` 的 name 为 `NoahLiu/native-gui`），包含全部库包：
`core` / `ui` / `render` / `text` / `theme` / `icons` / `sys` / `input` / `win` / `dbus` / `chart` / `mdview` / `web`。

**包路径与 mooncakes 上一致**（`NoahLiu/native-gui/core` …），本目录名只是仓库内的文件系统布局，
不进入包标识，因此 `moon add NoahLiu/native-gui` 的既有 import 不受影响。

仓库根目录的 [`README.md`](../README.md) 是项目主文档（架构、平台矩阵、构建方式、示例入口）。
