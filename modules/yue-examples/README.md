# NoahLiu/yue-examples

moonbit-libyue 的独立示例模块。这里的示例依赖媒体扩展等可选包，因此与主包的内置示例（`examples/`）分开维护。

## systemprobe

系统能力 + 扩展图表演示板：音量/亮度/浏览器与 VS Code 历史/应用查找等系统能力读取，雷达/热力/K 线/漏斗/箱线/桑基等扩展图表，以及媒体播放页（音频/视频组件）。

```sh
moon run NoahLiu/yue-examples/systemprobe
```

依赖：[moonbit-libyue](https://mooncakes.io/docs/NoahLiu/moonbit-libyue)、[yue-media](https://mooncakes.io/docs/NoahLiu/yue-media)、[ffmpeg-mbt](https://mooncakes.io/docs/NoahLiu/ffmpeg-mbt)（需系统 ffmpeg 开发包）。
