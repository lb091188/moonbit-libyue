# 路线图

## 定位

MoonBit 的**轻量跨平台桌面 GUI 框架**——窗口原生直连、渲染管线自绘、界面组件齐全、系统接口完备。

- **窗口原生直连**：窗口宿主与事件循环直连平台原生接口自研，不套平台控件包装；平台差异收敛在窗口、文字、图像解码、WebView、媒体五处 C 薄层
- **渲染管线自绘**：布局、光栅化、文字排印、控件与主题全由本库实现，三平台外观一致；深浅色与系统强调色默认跟随
- **界面组件齐全**：控件族、图表、Markdown 视图、WebView 与媒体播放开箱可用；功能各自成包，不 import 不进二进制
- **系统接口完备**：托盘、通知、全局快捷键、文件对话框、硬件与桌面设置面按平台后端实现；能力探测 + 语义化降级，不支持的环境给 `Unsupported` 而不是崩

## 现在能拿到什么

| 入口 | 内容 |
|---|---|
| 库 | `moon add NoahLiu/native-gui`——15 个子包（G9 Batch 2 拆出 base/shell 后），另有 gui-media、gui-webview、gui-examples 三个可选独立模块 |
| 示例 | `hello` 最小窗口、`hello-themed` 主题控件集、`showcase` 全功能演示板 |
| 文档 | 中英双语文档站与各包文档，见[文档索引](README.md) |
| CI | Linux 与 Windows 两条 job 每次推送全绿：库包测试、构建、虚拟显示下启动冒烟 |

## 平台现状

- **Linux**：X11 为主链路；Wayland 会话可运行，依赖 X11 的能力按会话探测降级。兼容跨度 **deepin 20 ~ Ubuntu 26**，工具包**留守 GTK3**（理由见「明确不做」）。
- **Windows**：能力族已验，CI 覆盖；真机验证矩阵部分待核。
- **macOS**：后端在 `mac` 分支落地中，**尚未合流 master**；master 上走占位实现，门面一律给 `Unsupported`。合流前置是真机验证收口。

## Linux 兼容档位

承诺跨度 deepin 20 ~ Ubuntu 26，验证按「库版本 × 桌面环境 × 会话类型」选代表档位，不按发行版数量堆测：

| 档位 | 代表 | 关键变量 | 状态 |
|---|---|---|---|
| 地板 | deepin 20 | GTK 3.24.5、webkit2gtk-4.0、ffmpeg 4.1、glibc 2.28 | 待验证 |
| 主链路 | Ubuntu 24.04 + X11 + XFCE | 开发机与 CI 所在档 | 已验证 |
| 天花板 | Ubuntu 26 | GTK3 是否仍随发行版提供、webkit 4.1+ | 待验证 |

当前待核项：

- **内嵌 WebView**：构建只探测 webkit2gtk-4.1，地板档缺该包时 web 退为占位实现；要承诺地板档需加 4.0 回退探测。
- **GTK API 地板**：窗口桩用到的 GTK 函数与 3.24.5 逐个核对，确认没有更新版本才引入的调用。
- **媒体线**：地板档 ffmpeg 开发包与运行期 so 的版本兼容。
- **命令线能力**：音量、夜灯、显示器、空闲所依赖的系统工具在地板档是否默认安装；未装即语义化降级，写进清单而不是当缺陷。
- **工具链**：最新 moon 工具链在 glibc 2.28 上的可运行性，是地板档构建的第一道闸。

验证方式：构建与无头判据在 VM / 容器上跑，能不进 GUI 的都不进；需要人眼的项进人工清单。

## 承诺与版本

- 当前版本 `0.1.1`：**0.x 阶段接口随批次演进**，破坏性改动在提交信息写明并同步文档。
- **稳定面清单与 1.0 时点待定**：落定后本节按「承诺面 / 实验面」逐包列出。

## 接下来的方向

1. **上手门槛**：首页给「装 moon → `moon add` → 出窗口」的最短路径；每平台前置依赖一句话说清；缺依赖时构建报错自带修复提示。
2. **可信度**：CI 门禁 + 真机人工清单 + 版本承诺，能力族验收一律走这三件套。
3. **内容**：文档站、组件文档、教程与 showcase 持续补齐；组件文档配图，教程给可运行的最小工程。
4. **治理**：issue 模板与贡献指南随对外投放建立；本文与平台矩阵随每批更新，不积压。

## 待定决策

- **macOS 纳入对外承诺的时点**：前置是 mac 分支真机验证收口。
- **稳定面清单与 1.0 时点**：逐包划分承诺面 / 实验面后，本文与各包文档同步。

## 明确不做

- **无障碍**：自绘文本栈暂不含，只记不办。
- **单平台能力进跨平台门面**：只有单一平台实现的能力不做门面，也不留挂账。
- **Linux 工具包升级**：留守 GTK3，它是 deepin 20 到 Ubuntu 26 的公共交集；不引入 Qt。脱 GTK 的唯一形态是降为可选后端。
- **原生控件皮肤**：不作主题化路径；按平台开关的原生兜底例外需逐条登记评审。
- **按参考实现平移接口**：接口由真实用例驱动，不为对齐而补。
